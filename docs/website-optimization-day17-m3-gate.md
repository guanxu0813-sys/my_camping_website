## 当前闸门缺口

需要同一固定窗口的以下数据：

1. **GA4 最近完整 28 天**：sessions、Organic Search sessions、engaged sessions、Organic Search engaged sessions，以及 `compare_selected`、`product_modal_open`、`outbound_click` 的事件次数和对应会话。
2. **GSC 最近完整 28 天**：总 clicks、impressions、CTR、average position，并分别导出查询和网页数据。
3. **集群证据**：Naturehike 与 Big Agnes URL 的 clicks、impressions、查询数及其占全站比例。
4. **引用证据**：GSC Links 或其他已验证来源中的最新 referring domains、top linking sites 和新增相关引用。

建议使用最近一个 GSC 已完整覆盖的 28 天作为当前窗口，并使用紧邻的前 28 天作为比较窗口。GA4 使用完全相同的日期，避免不同窗口造成假增长。

## 收到数据后的判断规则

- **进入 M4 小批量候选**：至少一个现有集群仍有真实点击，查询意图明确，并满足“至少 100 次集群展示、1 次点击、3 个不同查询”的最低扩展证据；同时高意图事件没有明显追踪故障。
- **继续 FOCUS**：有展示或点击，但自然参与、高意图事件和相关引用没有形成足够证据。继续优化现有赢家页、数据质量和分发，不扩大 URL 数量。
- **转为 REPAIR**：自然访问或高意图事件明显下降，或事件、来源、索引数据存在追踪/技术异常。先修复测量与用户路径。
- 引用域名和高意图事件用于验证流量质量，不能用社交曝光、视频播放或页面数量代替。
