## 保留

1. **保留每日生成与结构化数据验证。** 它能在内容发布前发现链接、页面和 schema 回归。
2. **保留完整比较漏斗审计。** 网站真正的使用价值来自“指南 → 比较 → 产品 → 官方来源”，不能只看页面数量。
3. **保留单页、来源驱动的优化方式。** DABAN 2 只改一个有展示的页面，并把售罄、重量差异和价格冲突讲清楚。
4. **保留过期数据标注。** 没有新 GSC 导出时，任何页面队列都必须写明数据窗口和确认日期。
5. **保留 Naturehike 与 Big Agnes 两个已验证集群。** 最后确认数据支持这两个集群，暂无证据扩展第三个集群。

## 停止

1. **停止批量改标题和摘要。** 旧实验均因样本不足关闭，不能把组级方向当作模板赢家。
2. **停止以旧价格或库存状态吸引点击。** 来源冲突时隐藏数字并解释限制，比展示一个看似精确的错误值更可信。
3. **停止宽泛新增页面。** 最近确认的访问仍低于增长门槛，继续增加 URL 会稀释质量检查。
4. **停止用展示量、社交播放或页面数量代替有效使用。** 后续仍以自然访问、比较行为、Modal 和站外点击为主。
5. **停止提前评价 DABAN 2。** `EXP-2026-10-24-DABAN-01` 最早到 2026-11-21 且达到 300 次改后展示才能判断。
