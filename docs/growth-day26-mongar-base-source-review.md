## Corrected anomaly

The local catalog previously used 3.1 kg for Base 2 and 3.8 kg for Base 3.
Those values match storefront variant weights but conflict with the official
technical specification section. They are excluded from the comparison.

The catalog now uses **total weight with accessories** as its representative
weight: 2.75 kg and 3.4 kg. It also stores the corresponding minimum weights,
2.33 kg and 2.85 kg, as separate fields. The guide must label both columns and
must never combine them.

## Conclusion before table

- Base 2 is the lower-load choice for solo use or two campers who can live with
  the smaller interior.
- Base 3 buys one additional listed sleeping place and more usable room, but
  adds about 0.52 kg minimum or 0.65 kg with the full listed accessory kit.
- Both use the same listed fabric, waterproof rating, pole material and core
  accessory set, so the defensible decision is primarily capacity, space,
  carried weight and price.

## Limitations and uncertainty

- This is an official-spec comparison, not hands-on testing.
- Capacity labels do not prove comfort for three adults plus equipment.
- No claim will be made about wind or storm performance.
- Dimensions and packed sizes must be copied from each current technical-spec
  block when the guide is built; image text is not accepted as the only source.
- Regional prices, discounts and availability can change.
