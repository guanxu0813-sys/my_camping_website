## 为什么处理这页

最后确认的 GSC 窗口为 2026-08-05 至 2026-09-01：DABAN 2 获得 28 次展示、0 次点击、平均排名 6.57。它已经进入较靠前的搜索位置，但旧标题仍突出 139 美元，且页面把产品标成 `InStock`，与当前官方信息不一致。

## 来源复核

2026-10-24 复核 Naturehike 官方 DABAN 2 页面后确认：

- 页面说明产品售罄，且售完后不再补货。
- 产品文案给出约 3.2 lb（约 1.45 kg），嵌入的变体数据则为 1600 g，因此站内继续使用“约 1.6 kg”并明确差异。
- 产品页显示 189 美元，官方分类页同时显示 259 美元，价格存在冲突，因此不把任一数字当作当前可靠价格。
- 可稳定确认的规格包括两人、四季、隧道结构、15D 外帐、20D 底布、3000 mm+ / 4000 mm+ 防水指标。

## 本次改动

1. 标题和摘要移除过期的 139 美元，改为型号、人数、重量、季节和防水信息。
2. 首屏直接说明产品已售罄且不再补货，避免把规格页误导为购买入口。
3. 关键规格中的价格改为“不可用”，并说明官方价格显示冲突。
4. 删除该页 JSON-LD 中旧的 139 美元 `InStock` Offer。
5. 新增来源日期、重量差异和价格限制说明。
6. 新增 DABAN 1 与 DABAN 2 的直接比较按钮，帮助精确型号查询用户进入实际比较流程。
7. 生成器只在页面覆盖配置存在时启用这些能力，没有把改动扩展到全站产品模板。

## 判断规则

这是单页观察实验，不是已确认的赢家。基线为 0 点击、28 展示、0% CTR、平均排名 6.57；最早判断日为 2026-11-21，且至少需要 300 次改后展示。没有有效匹配对照页，因此只能把结果作为该页的方向证据，不能复制到其他页面。
