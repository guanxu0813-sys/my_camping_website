How to choose

  • Hornet: NEMO positions it as the ultralight option, using a minimal pole structure and Flybar for added volume.
  • Dragonfly: the listing emphasizes a freestanding frame and balance between weight and livability.
  • Dagger: NEMO describes it as the roomiest, most livable backpacking option of the three.
  • Price: current ranges overlap by capacity; verify the exact person-count variant before comparing totals.
  • Data limitation: the current catalog lacks normalized weights for these multi-variant listings, so this page does not invent a single figure.

Method and limitations

This is a specification comparison, not a hands-on review. Weights and prices can vary by size, fabric, season and market. We use representative values from brand listings and link the source so you can verify the exact variant before buying.
